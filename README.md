
# SpendWise Dashboard - Week 4

## Project Description

SpendWise is a modern personal finance dashboard designed to help users monitor their income, expenses, savings, and financial activities.

This project focuses on building a responsive dashboard layout using CSS Grid and Flexbox.

## Project Author

FARDOWZA ALI HASSAN

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox
- CSS Custom Properties
- Responsive Web Design

## Project Structure

### 1. index.html

Contains the dashboard structure, including:

- Sidebar navigation menu
- Dashboard header
- Financial summary cards
- Six expense category cards
- Recent transactions
- Footer

### 2. style.css

Controls the dashboard appearance and layout.

It includes:

- CSS Grid for the main dashboard layout
- Flexbox for navigation, header and cards
- CSS variables for the color theme
- Responsive media queries
- Hover and keyboard focus animations
- Dark theme support
- Progress bars and card styling

### 3. README.md

Explains the project, technologies and features.

## Dashboard Categories

## Key Features

- Modern dashboard interface
- Responsive mobile layout
- Financial summary cards
- Expense category cards
- Recent transaction section
- Interactive card hover effects
- Keyboard accessible category cards
- Automatic dark theme based on system preference

## Responsive Design

The dashboard changes into a single-column layout on screens smaller than 768px.

## How to Run

1. Clone or download the repository.
2. Open the project folder.
3. Open index.html in your browser.
4. Resize the browser to test the responsive layout.
